# 桃源（暂定名）

连作短篇集。舞台是一个不点名的苏北县城（原型：泗阳，古称桃源县）。
悬疑为骨，时间为线，父子为心。

## 一句话

一条死了一百七十年的河，每隔几十年会“回来”几天。河回来的时候，过去和现在是通的。
